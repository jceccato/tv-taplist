## Notes

- Drawn as strokes over the pour, not fills - `stroke="rgba(255,255,255,0.20)"`,
  `stroke-width="3"`. They are highlights in the glass, not holes in the beer.
- Both grids run wider than the pour in places, so the outer column clips at the
  edge. That is deliberate - a dimple cut off by the profile reads as curvature.
  If it reads as an error instead, pull `step` in.
- The symmetriser folds a closed loop about x=150. The pour is one; the dimple
  grid is fifteen separate loops and the handle is one-sided, so neither can be
  folded. Both are placed by hand or derived, like the foam and bubbles.
