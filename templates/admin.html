Taps & Display

Card sizing

Scales the beer photo and the card text on the display, for screens the defaults do not suit. The two are independent: picking a preset sets its own slider, and moving a slider switches that preset to Custom. Photo scale only shrinks - the photo already fills the space the card text leaves it, so there is nothing above Default to give it. A larger text preset takes room from the photo, by design. Card padding and the colour swatch are unaffected, and the text keeps its pixel floor, so no scale can make the board illegible.

Export a Snapshot

A Snapshot is this board as it stands right now, packaged as a zip that mirrors your data directory: settings, every tap file and photo from both sources, the archived beers, and your venue logo. Restoring one is unpacking it - you can import it here, or unzip it straight into the data directory of a stopped box.

It never contains the sync status or the .data_dir_id file. Both belong to the box, not to the data.

{% if snapshot_credential_option %}

The Snapshot is not encrypted. Ticking this writes your Brewfather API key into the zip in plaintext, so treat the file like the key itself. Leave it unticked and the Snapshot's Brewfather fields are blank - you paste the key in after restoring.

{% endif %}

Import a Snapshot

Restoring replaces any file the Snapshot carries and leaves everything else alone. A file that is not a Snapshot is refused whole, with nothing changed.
